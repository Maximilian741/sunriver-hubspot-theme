A

Audit log Security

An immutable record of every privileged action in a system, who did what, when, from where. Required for SOC 2 and most compliance frameworks.

Auto-scaling Cloud

Automatic adjustment of compute capacity based on real-time demand. Done well, it saves money. Done badly, it masks performance problems and runs up the bill.

B

BAA, Business Associate Agreement Healthcare

A contract between a HIPAA-covered entity and any vendor that handles Protected Health Information. We sign one before any healthcare engagement begins.

Blue/green deploy Delivery

A deployment pattern that runs two identical production environments and switches traffic between them. Reduces downtime and makes rollback instant.

C

CI/CD, Continuous Integration / Delivery Delivery

Automated testing and deployment of code changes. The shorthand we use for 'every commit gets tested, every green build can ship'.

Cutover Migration

The moment traffic moves from an old system to a new one. The most-rehearsed five minutes of any migration engagement.

F

FinOps Cloud

The practice of bringing financial accountability to cloud spend. Less 'cut the bill', more 'understand the bill so you can decide what's worth it'.

H

HIPAA Compliance

US healthcare data privacy law. If your system touches PHI, it applies. We design environments that meet HIPAA without requiring engineers to think about it daily.

I

IaC, Infrastructure as Code Delivery

Defining infrastructure (servers, networks, databases) in code instead of clicking through a UI. Makes changes reviewable, reproducible, and auditable.

R

Runbook Operations

A written, step-by-step procedure for handling a known scenario, incidents, deploys, on-call escalations. We ship runbooks with every engagement because tribal knowledge doesn't survive turnover.

S

SOC 2 Compliance

An audit framework focused on security, availability, processing integrity, confidentiality, and privacy. Type II is the one most enterprises ask for.

SRE, Site Reliability Engineering Operations

The discipline of treating reliability as a first-class engineering concern. SLOs, error budgets, runbooks, post-mortems, all of it.

T

Terraform Cloud

The most common tool for Infrastructure as Code. We default to Terraform on most engagements unless the client already has a strong reason to use Pulumi or CDK.
